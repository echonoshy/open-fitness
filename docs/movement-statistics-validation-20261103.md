## 视频规则和参考小人

- 使用全部 582 段本地演示视频，按约每秒 8 帧提取 MediaPipe Full 的 33 个关键点。模型与应用现有 Full 模型相同，提取为离线维护步骤，应用运行不依赖 Python。
- 按推、拉、屈肘、屈膝、髋部屈伸、肩部抬举、躯干转动、静态保持等动作族分配信号。每个动作依据视频选择双侧平均、较小值或较大值，校准幅度下限；不能形成稳定周期的候选改用活动计时。
- 计数使用平滑、幅度门槛、完整往返、最短周期和丢点重置；暂停、休息、关闭摄像头都清除未完成周期，保留已记录总数。
- 580 个动作的小人由各自视频的两个代表姿态生成。雪橇拉与双力臂的视频人体提取失败，参照对应封面和动作步骤补画了两阶段示意。全部 582 个动作都有小人数据，原有九个动作继续显示原有机位指引。
- 视频姿态提取参考 [MediaPipe Pose Landmarker 官方 Python 文档](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/python)。示意图中的遮挡关节可能省略，不作为标准动作评分。

实现：`desktop/src/core/movement-statistics.ts`、`movement-calibration.json`、`timed-training.ts`、`components/MovementGuide.tsx`、`movement-guide-poses.json`。维护入口：`desktop/scripts/extract-movement-poses.py` 和 `calibrate-movement-statistics.ts`。

## 训练、记录和数据

- 计数动作按次数目标显示；保持、活动和普通计时按秒数显示。拒绝将秒数目标悄悄写入计数目标，避免目标与界面不一致。
- 训练总时长、摄像头估算次数、姿态/活动累计秒数与手动次数分开保存。手动值作为当前显示值，自动估算保留供对照；不生成新动作的评分、纠错、个人纪录或自动计划。
- 摄像头关闭后，姿态统计停止，训练总时长继续；离开训练页时整组暂停。支持负重、休息、换组、切换动作先保存、正常关闭保存和意外中断恢复。

- 数据版本为 v4，完整 JSON 备份包含统计与修正。桌面首次保存保留前一版本备份。独立测试数据从 v3 成功升级到 v4，保留 `data.json.v3.backup`，完成组的检查点已清除。

## 使用边界

本版落实“广覆盖、允许粗略统计”的要求。新增统计以用户选择的动作为前提，没有判断用户实际正在做哪一种动作；机位、遮挡、速度和动作幅度都会影响结果。视频标定与固定输入运行验证不是独立的准确率测试。没有完成 582 个动作的真人逐项验收，也没有新增动作的动作质量评分、远场语音或全设备现场验收结论。
