# open-fitness 试用说明

适用版本：0.3.48，macOS Apple Silicon。安装包已包含客户端与 MediaPipe Pose Landmarker Full 本地推理模型，姿态识别统一使用 Full，无需选择模型，也不需要安装 Node.js 或 Python；语音教练需要连接配置的 AI 服务。

## 安装与首次使用

1. 将完整的 `open-fitness.app` 放入「应用程序」后双击打开。项目工作区也可直接双击 `desktop/release/mac-arm64/open-fitness.app`；更换前正常退出旧版。
2. 当前包使用内测临时签名，未经过 Apple 公证。系统拦截时，在确认来源后使用 macOS 的「隐私与安全性」允许打开。
3. 在设置中选择摄像头、麦克风、扬声器，授予系统权限。首次授权后优先匹配 viaim Connect，也可手动换设备。
4. 打开「设置 → AI 服务」。公开版首次使用时填入自己的 Agent Plan Key，点「测试连接」，三项通过后点「保存并生效」。内测包如显示「已配置」，可以直接使用，也可在这里替换 Key。
5. 运行「语音与设备检查」，确认连接与权限状态，再开始真实训练。

viaim Connect 在这里作为摄像头、麦克风和扬声器外设使用，教练应用与本地推理运行在 Mac 上。

## 开始训练

训练页开启摄像头后，按画面提示站位，选择动作并开始单组训练。深蹲采用侧面拍摄，保持同侧肩、髋、膝、踝完整入镜，等待侧身和站立稳定检查通过。完成动作后回到起始位置，再开始下一次。

九种动作包括深蹲、俯卧撑、卧推、硬拉、弓步蹲、肩上推举、二头弯举、引体向上和平板支撑。自由训练使用你选定的动作，计划训练按计划顺序切换。选好动作后，系统按该动作的规则计次或计时。不同动作对拍摄方向和入镜关节有不同要求。

自动取景会在站稳后按远近调整，尽量让全身高度占画面约三分之二，最多放大3倍。走近后自动缩小，缩小到完整原始画面仍无法容纳全身时，需要后退；软件无法补出镜头外的身体。转身或短暂遮挡远侧手部时保持构图，动作中不会追着每次下蹲放大。语音“放大一点”会按人物大小明显拉近；“稍微放大一点”才微调，“放大到2倍”直接指定倍率。自动取景时语音缩放继续跟随，固定时继续固定。可说“太大了，回到刚才”或点击“撤销上次调整”，恢复上一次取景和模式。按钮微调或左右调整后保持固定；需要跟随时点“恢复自动取景”或说“跟着我”，恢复默认约65%的大小。未看清全身或正在动作中，会先记住要求，站稳后调整。

自由训练达到目标后会提示，可继续训练，点击结束保存本组。计划模式按设定目标自动保存、休息、推进到下一组。切换动作会保存当前组；关闭摄像头会暂停训练。控件隐藏后可用右下角入口或 Esc 恢复。

## 与教练对话

开启摄像头时默认接通语音教练，可以直接说「这组做十次」「暂停训练」「开始休息一分钟」。说话会打断正在播放或处理中的旧回复，停顿后识别新一句话。已执行的训练操作不会因打断而撤销。

当前界面通过语音输入，支持训练设置、计划、历史查询、动作资料和长期资料管理。静音按钮停止收音；摄像头与麦克风独立，关闭摄像头保留麦克风当前开关，离开训练页停止收音。人声检测没有说话人识别或唤醒词，旁人的声音可能触发。

在「设置 → 教练声音」可试听四款男声和四款女声，初次使用默认「女声 1 · 清透自然」。点击「使用此声音」后，训练报数和教练在线回复使用所选音色。

## 记录和备份

记录页查看逐次明细与趋势，并可将已完成动作保存为个人参考。删除的计划在「计划 → 最近删除」恢复，资料和参考动作在「我的资料 → 最近删除」恢复。

换设备或升级前，在「设置 → 数据与备份」导出完整 JSON。Strong / Hevy CSV 用于记录交换，不包含完整姿态评分与节奏信息。桌面端与浏览器端各自保存数据，可用 JSON 合并迁移；清除浏览器站点数据前请备份。

需要查询或分步处理时，模型可以先说一句贴合请求的意图，例如“我来查一下你上周的深蹲记录”，不再每次固定说“稍等”。执行结果以实际收据为准，最终回答保留。随时开口或点击“停止回复”可打断；已经完成的操作保留，尚未完成的部分停止。

教练会在进入训练且收音就绪后问候，并在训练关键进度、持续动作问题、休息转换和结束时适度主动说话。默认“适中”，一组最多两次中途进度，次数过时不补播；不会把计次成功说成动作标准。到“设置 → 教练声音”调整主动提醒频率，或直接说“少说一点”“多鼓励我”“恢复适中提醒”。动作纠错开关仍单独控制站位和动作问题提示，关闭总语音开关则停止所有播报。

摄像头视频与姿态分析在本机运行。开启语音教练后，语音片段、对话和所需训练记录/资料会发往配置的服务。新安装的记录位于 `~/Library/Application Support/open-fitness/data.json`，已有安装沿用同级旧目录 `Viaim Coach/`。

「设置 → 关于与版本」可查看代码与素材许可。动作演示来自 MoveKit，现有素材仅供内部参考；转载或用于其他产品需取得相应授权。

## 反馈问题

提供「设置 → 关于与版本」中的版本号和构建时间，并说明动作、拍摄方向、设备、画面提示和复现步骤。漏计时记录当时角度、阶段、站位检查和身体侧别；语音问题说明是识别错误、响应慢、未执行还是无法打断。

当前试用范围和待检查项见 [验证清单](validation.md)。自动化测试通过、画面出现骨架或服务诊断成功，都不能单独证明实际计数与语音效果。
