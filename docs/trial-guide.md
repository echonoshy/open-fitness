# open-fitness 使用指南

open-fitness 在配备 Apple 芯片的 Mac 上运行。安装包已包含应用和本地姿态模型。浏览动作、安排计划、计次或计时，以及保存训练记录，都无需 API Key。

## 完成第一组训练

1. 将 `open-fitness.app` 放入「应用程序」并打开。在设置里选好摄像头，按 macOS 提示授予权限。使用 viaim Connect 时，可以将它选作摄像头或音频设备。
2. 在「训练」页选择深蹲，开始训练后按提示侧身站好，让同侧肩、髋、膝、踝完整入镜。等待站位检查通过，做一次深蹲并回到站姿，再看计数。
3. 完成本组后结束并保存，在「记录」中查看结果。希望下次重复同样的训练，可以在「计划」中保存动作顺序、负重、组数、目标次数或时长，以及休息时间。

## 选择动作和记录方式

在「动作库」按名称搜索，或按肌群、器械和难度筛选。可以查看已安装的演示、收藏常练动作，然后从训练页开始。

深蹲、俯卧撑等基础动作按专用规则计次，平板支撑按姿态保持时间记录。其他动作会标明估算计数、保持计时、活动计时或普通计时。手动填写的次数与摄像头估算值在记录中区分展示。

取景时先按动作提示调整相机位置和距离。自动取景可随站位调整画面，原始画面容不下全身时需要后退。关闭摄像头会暂停基础动作训练。动作库的计时训练可以继续计时，此时不会增加摄像头测得的次数或保持时间。

## 使用语音教练

在「设置 → AI 服务」填入自己的 Agent Plan Key，点击「测试连接」，通过后点「保存并生效」。在「教练声音」试听并选用音色，再打开训练页的麦克风。若听不到声音，可在设置中检查麦克风、输出设备及「语音与设备检查」。

训练中可以说「这组做十次」「暂停训练」或问「深蹲时怎么呼吸」。教练播报时可以开口打断。常规训练与动作库计时训练支持的指令有所不同，以界面显示的动作与实际执行结果为准。主动提醒频率可在「教练声音」中调整。旁人的声音也可能触发识别，需要时可将麦克风静音。

摄像头画面和姿态分析留在本机。使用在线教练时，语音片段、对话和必要的训练上下文会发送给所配置的服务。

## 备份与排查

- **换设备或恢复训练资料。** 在「设置 → 数据与备份」导出完整 JSON，包括计划、常练动作、训练记录和手动修正。桌面和浏览器各自保存资料，可通过 JSON 迁移。Strong / Hevy CSV 用于交换基础动作的计数与姿态计时记录。
- **反馈漏计或语音问题。** 记录动作名称、拍摄方向、使用的设备、屏幕提示和复现步骤。「设置 → 关于与版本」可查看版本、构建信息和使用许可。

开发与打包见[开发维护指南](../desktop/README.md)，实际摄像头和语音的检查方法见[验证清单](validation.md)。
