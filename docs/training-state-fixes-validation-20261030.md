# 训练计时、设置保存与备份恢复修复验证

日期：2026-10-30（北京时间）。基于 0.3.24 / `3a71dfc` 的未发布源码修复，未提升版本、生成分发包或替换现有 App。

## 修复行为

### 平板支撑排除站立计时

- 在现有身体直线角度判断之前，检查同侧肩髋、肩踝向量的朝向。按画面比例修正朝向计算，保留深度分量，以兼容正面和斜侧面投影；其他动作的角度约定、计次阈值和状态机保持原样。
- 站立或朝向不符合支撑要求时停止计时并显示就位提示，清除当前连续支撑状态；总有效时长、历史最佳连续时长、组 ID 和训练 ID 保留。
- 重新俯身支撑后通过原有稳定准备检查再计时，不补计站立或重新就位期间的时间。
- 此检查用于排除直立姿态，不证明地面接触，也不是完整的平板姿态评估。镜头大角度倾斜、深度估计偏差等仍需实际设备验证。

### 设备刷新保留最新设置

- 设备列表读取完成后，在串行保存任务真正执行时，以最新设置解析设备选择；仅改变设备相关字段。
- 已排队的静音、音色、提醒密度、背景虚化设置以及训练记录不会被枚举开始时的旧状态覆盖。
- 保存失败后的队列恢复和既有设备匹配规则保持不变。本次未修改摄像头/麦克风“系统默认”的选择策略。

### 备份包含中断进度

- 数据页实际 JSON 导入流程复用检查点恢复逻辑，将备份中未归档的检查点转换为中断记录后合并，不自动开始或接续计数。
- 同 ID 的完整记录优先，重复导入幂等；导入不改变本机设备设置及当前检查点。
- 若导入内容的 ID 属于本机当前检查点，暂不归档该条导入快照，避免本组结束时完整记录被旧快照去重跳过。
- 检查点仍每 5 秒保存；本次没有改变保存频率。备份包含的是最近已保存的进度。
