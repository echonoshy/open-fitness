# 音色维护

## 2026-11-02：Agent Plan 在线语音

本机当前使用豆包 ASR 2.0 / TTS 2.0，复用主模型的 Agent Plan Key。实际配置保存在应用用户目录的 `services.json`，不将 Key 写入仓库或前端。语音请求使用 `https://openspeech.bytedance.com/api/v3/plan`；ASR 通过 WebSocket 上传已录好的句子，TTS 通过 HTTP Chunked 返回 PCM。

原有八个选择 ID 保持稳定，对应的在线声音改为官方 TTS 2.0 音色，映射见 `agentPlanSpeaker`。这些是替代声音，不是旧 W01/P8 等定制声音的复刻。设置页试听改为实时合成，试听与当前在线回复使用同一音色。已经保存的声音选择不变。

历史参考母带、离线试听文件和动作示范的预录讲解继续保留；播放这些文件不访问原自部署 API。预录讲解与新在线回复的音色可能不同。下面的注册与速度说明仅适用于历史 VoxCPM 服务，Agent Plan 不运行音色注册脚本。

验证记录与复测方法见 [Agent Plan 语音接入验证](agent-plan-speech-validation-20261102.md)。

## 历史 VoxCPM 音色

2026-10-21 已确认八款声音，应用默认 W01，男声首选 P8。偏好为清楚自然的标准普通话，无方言、中等语速、短句间自然停顿。

| 候选编号 | 界面名称 | 选择 |
| --- | --- | --- |
| N6 | 男声 1 · 温润细致 | 保留 |
| P4 | 男声 2 · 清楚直接 | 保留 |
| P5 | 男声 3 · 沉着低音 | 保留 |
| P8 | 男声 4 · 成熟坦然 | 男声首选 |
| W01 | 女声 1 · 清透自然 | 应用默认 |
| W04 | 女声 2 · 轻松随和 | 保留 |
| W13 | 女声 3 · 活力自然 | 保留 |
| W18 | 女声 4 · 清透温和 | 保留 |

应用使用 [voices.ts](../desktop/src/core/voices.ts) 的八个固定 ID，试听文件位于 `desktop/public/voices/`。注册所需参考母带、设计说明、原候选来源与校验值在 [selection.json](../desktop/assets/voices/selection.json) 及其 `references/` 子目录，保留原始已确认音频，不通过重新生成替代。

`selection.json` 内音频路径相对该文件所在目录，`referenceSha256` 和 `sampleSha256` 可核对母带与试听。母带属于维护资产，不随前端静态目录打包。早期六款未采用声音、候选生成脚本和试选报告已移除。

需要在新 TTS 服务恢复音色时，先确认服务配置，再在 `desktop/` 执行：

```sh
COACH_SERVICES_CONFIG=/绝对路径/services.json npm run voices:register
```

该命令会向目标服务器上传缺失的八款音色参考，跳过已经存在的 ID，不重新生成试听。正常开发、构建和本地测试不会执行注册；本次清理也未对服务器音色做更改。

VoxCPM2 流式合成使用 `speed=1`，保留音色与参考文字；非流式试听请求使用已确认的速度设置。修改音色时需同时核对客户端列表、注册元数据、试听文件与服务器 ID。

0.3.6 由模型按当前请求生成简短意图，再使用当前所选音色合成；不再固定播放同一句等待录音。八款已确认音色与参考母带保持不变，旧等待录音和生成脚本退出活动目录。
