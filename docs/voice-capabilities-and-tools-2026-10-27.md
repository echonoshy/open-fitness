# 语音交互功能与工具清单

核对日期：2026-10-27。核对对象：当前工作区的 viaim Coach 桌面端源码，`desktop/package.json` 版本为 0.3.13。

当前注册了 **23 个模型可调用工具**：12 个训练控制、2 个摄像头与取景控制、2 个播报与提醒控制、4 个只读查询、2 个用户资料写入/遗忘、1 个不操作决策。另有本地语音快捷指令和主动陪练机制。

本清单已同步本次鲁棒性修复。344项自动化测试通过，98条文字用例、4种真实模型取消时序、8条合成语音链路通过验证；其中文字用例71条调用真实模型、27条走本地路径。具体证据和边界见[修复与验证报告](voice-robustness-fix-validation-2026-10-27.md)。尚未做真人麦克风、扬声器回声和真实摄像头现场验收。

## 用户可以通过语音做什么

| 功能 | 可以说的话 | 实际行为与边界 |
| --- | --- | --- |
| 控制训练 | “开始训练”“停止”“停下来”“不做了”“继续”“结束并保存” | 短促的停止/停下来先暂停并保留进度；不做了/结束训练/停止训练结束并保存。开始/继续时按需开启摄像头；先做准备检查，满足条件后计数。 |
| 新开一组 | “再来一组12次”“再来一组” | 归档当前组，同一动作从零开始；没给目标时沿用目标。计划进行中不允许另开自由训练组。 |
| 修改本组目标 | “这组改成15次”“平板支撑目标设为45秒” | 只修改目标，保留本组已有次数或有效支撑时长。 |
| 切换动作 | “换成俯卧撑”“切换到肩上推举” | 支持 9 种实时训练动作。重复选择同一动作默认不清零；计划中不能直接切换。 |
| 设置训练参数 | “重量设成10公斤”“下放节奏设为3秒”“休息90秒” | 修改负重记录、下放节奏参数，或开始休息倒计时。未指定休息时长时使用60秒；必须已有进行中的训练才能开始休息。 |
| 多动作计划 | “开始自重训练：深蹲2组每组12次，俯卧撑2组每组8次，每组休息60秒” | 通过训练块执行组数、目标、休息和负重安排。工具启动后立即进入计划；未明确组数或次数时，提示词要求先询问。 |
| 自动识别动作 | “开启自动识别”“关闭自动识别” | 本地规则识别。开启需在一组训练开始前；卧推需要手动选择。 |
| 当前状态问答 | “我做了几次？”“还休息多久？”“为什么还没开始计数？” | 根据当轮状态快照回答，包括次数、目标、计时、准备检查、跟踪和取景状态；没有单独的状态查询工具。 |
| 摄像头与画面控制 | “关闭摄像头”“放大一点”“固定画面”“恢复自动取景” | 开关摄像头，控制本地显示裁切、缩放和跟随。关闭摄像头会暂停训练、保留进度，麦克风独立。 |
| 历史查询 | “看一下我上周的深蹲记录”“最近30天练了多少组？” | 查询真实本地记录，支持动作、日期、周/月筛选，并返回汇总、趋势、个人记录和最近训练。 |
| 动作与训练知识 | “只有哑铃，可以做哪些胸部动作？”“俯卧撑怎么做？” | 查询本地动作与训练知识，支持器械、肌群、难度过滤。一般热身、恢复、饮食等问题可走简短建议回答。 |
| 杠铃配片 | “总重60公斤，每边怎么配片？” | 根据杠铃杆重量和片重规格计算每侧配片；默认杆重20公斤，假设各规格有足够的成对数量。 |
| 保存/查询/遗忘资料 | “记住我家只有哑铃”“你记住了哪些训练偏好？”“忘记我的器械信息” | 保存用户明确表达的长期资料。遗忘需要定位具体分类与键；资料移入最近删除，可恢复。 |
| 调整提醒密度 | “请少说一点”“提醒少一点”“多鼓励我”“恢复适中提醒” | 本地完整短句或模型的set_guidance工具修改安静/积极/适中设置。保留动作纠错开关，安静模式仍保留阶段及问题提示。 |
| 控制播报 | “停止说话”“关闭所有语音播报”“恢复语音播报” | 停止说话会停止本次播报并暂缓主动播报，下次提问恢复；明确关闭全部播报则保存静音设置，直到恢复。麦克风与训练状态独立。 |
| 打断与追问 | 在教练说话时直接开口 | 检测到人声后取消当前生成、合成和播放，处理新一轮语音。打断不撤销已经执行成功的工具。 |

实时训练动作共 9 种：深蹲 `squat`、俯卧撑 `pushup`、卧推 `bench`、硬拉 `deadlift`、弓步蹲 `lunge`、肩上推举 `shoulder_press`、二头弯举 `curl`、引体向上 `pullup`、平板支撑 `plank`。其中平板支撑按有效时长记录，其余按次数记录。深蹲当前要求侧身准备检查；俯卧撑已接入正面、侧面与斜侧面检查，实际可判断范围仍受可见关节限制。

本地知识资源实际包含 **876 个动作条目 + 52 个训练知识条目，共 928 条**。动作知识可查询范围与实时识别/计数范围不同。

## 23 个工具完整列表

以下参数名来自当前实际导出的工具 schema。类型中的 `type` 被转换为工具名，不需要模型再作为参数传入。

| 类别 | 工具 | 作用 | 主要参数与限制 |
| --- | --- | --- | --- |
| 训练 | `session` | 开始、暂停、继续、结束、取消休息 | `action`: `start / pause / resume / end / cancel_rest`。结束会归档本次训练，应用层执行保存。 |
| 训练 | `new_set` | 保存当前组并开始同一动作的新一组 | 可选 `target`、`unit: reps / seconds`；次数1–100，平板支撑1–600秒；未指定目标则沿用。 |
| 训练 | `set_exercise` | 切换动作 | `exercise` 为9个动作ID之一；可选 `restart`。相同动作默认保留本组次数。 |
| 训练 | `set_rep_goal` | 修改当前组次数目标 | `reps`: 1–100整数；不清零；平板支撑不适用。 |
| 训练 | `set_hold_goal` | 修改平板支撑目标 | `seconds`: 1–600整数；当前动作必须为平板支撑。 |
| 训练 | `set_load` | 设置训练负重记录 | `kg`: 0–500；0表示自重，不控制任何实体器械。 |
| 训练 | `set_tempo` | 设置下放节奏参数 | `eccentric_s`: 0.5–10秒。当前更新状态与界面数值，未接入逐拍语音节拍器或依据此目标进行节奏纠错。 |
| 训练 | `rest_timer` | 开始休息倒计时 | `seconds`: 5–900；语音没指定时长时默认60秒；需有进行中的训练。 |
| 训练 | `start_program` | 立即启动多动作训练计划 | `blocks`: 1–20个训练块；每块包含 `exercise / sets / target / rest / load`；每块1–20组，休息0–900秒，次数目标最多100或平板支撑最多600秒。 |
| 训练 | `stop_program` | 结束计划并归档已完成内容 | 无参数；当前必须存在计划，应用层负责保存。 |
| 训练 | `auto_detect` | 开关本地规则动作识别 | `enabled` 布尔值；训练开始前开启；卧推手动选择。 |
| 训练 | `cues` | 开关动作纠错语音 | `enabled` 布尔值；也影响站位问题提示，不等同于关闭全部教练播报或麦克风。 |
| 播报 | `set_guidance` | 设置主动提醒密度 | `level`: `quiet / balanced / active`；持久化设置，不修改纠错开关和训练进度。 |
| 播报 | `speech_control` | 停止当前播报、关闭/恢复全部播报 | `action`: `stop / mute / unmute`；stop临时停止并在下次实际请求时恢复；mute保存关闭状态；均不关闭麦克风、不暂停训练。 |
| 画面 | `camera` | 开关摄像头 | `enabled` 布尔值；关闭保留训练进度并暂停，麦克风保持当前状态。 |
| 画面 | `camera_view` | 自动取景、固定、缩放、横移、撤销 | 必填 `action`；可选 `adjustment / zoom / factor`，详见下表。 |
| 查询 | `history_query` | 查询本地真实训练历史 | 可选 `exercise`；时间范围使用 `days`、`from/to`、`period` 三选一；`period`: `this_week / last_week / this_month / last_month`；`limit` 1–30，默认返回最近10条详情。 |
| 查询 | `exercise_lookup` | 检索动作与知识 | `query`，可选 `muscle / equipment / level`；难度为 `beginner / intermediate / expert`；单次最多5条匹配。 |
| 查询 | `plate_calc` | 计算杠铃每侧配片 | 必填总重 `target`；可选杆重 `bar`、片重数组 `plates`；默认杆20公斤，默认片重25、20、15、10、5、2.5、1.25公斤。 |
| 查询 | `profile_query` | 读取长期用户资料 | 无参数；返回已保存的事实条目。 |
| 资料 | `remember` | 保存或更新明确的长期事实 | 必填 `category / key / value`；同分类同键更新。 |
| 资料 | `forget` | 从教练可用资料中移除指定条目 | 必填 `category / key`；移入最近删除，不是立即永久删除。 |
| 决策 | `no_action` | 仅回答、解释或澄清，不改变应用 | 可选 `reason`；这是模型作出的不操作决策。 |

用户资料分类共有8种：`identity` 基本资料、`body` 身体情况、`goals` 训练目标、`injuries` 伤病与限制、`equipment` 可用器械、`schedule` 训练安排、`nutrition` 饮食偏好、`preferences` 其他偏好。`schedule` 仅保存文字资料，不创建日历事件或定时提醒。

`camera_view` 的10种操作如下：

| action | 语音示例 | 行为 |
| --- | --- | --- |
| `auto` | “跟着我”“恢复自动取景” | 恢复自动跟随和默认约65%的人物占比目标；实际取景受全身边界约束。 |
| `full` | “恢复全身”“恢复完整画面” | 恢复完整原始画面并固定。 |
| `lock` | “固定画面”“别跟着我” | 固定当前取景。 |
| `zoom_in` | “放大一点”“还是太小了” | 普通表达默认按人物占比明显拉近；明确“稍微”才微调。 |
| `zoom_out` | “缩小一点”“拉远一些” | 缩小至更完整的画面，最远是原始视野。 |
| `zoom_to` | “放大到2倍” | `zoom: 2`，设置绝对倍率。 |
| `zoom_by` | “放大一倍” | `factor: 2`，在当前倍率基础上乘2；相对倍率与绝对倍率分别处理。 |
| `undo` | “回到刚才”“撤销上次取景调整” | 撤销上一次取景调整，包括相关模式/目标变化。 |
| `left` | “画面往左一点” | 向左查看并固定取景。 |
| `right` | “画面往右一点” | 向右查看并固定取景。 |

缩放通常保留当前自动/固定模式，`left/right/full/lock/auto` 则按上述定义改变模式。缩放上限3倍，自动取景优先保留全身；人体未看清或正在动作中时，某些请求会等待站稳。`adjustment` 支持 `smart / fine / step`，其中 `step` 被提示词限定为界面按钮使用。所有取景均为本地画面裁切与显示变换，不会物理转动镜头，也不能扩展摄像头原始视野。

## 主动陪练与交互机制

无需用户逐次发命令，应用会依据本地训练状态尝试播报：进入训练后的问候、本组动作与目标、准备就绪、持续入镜/站位问题、稳定出现的动作问题、组内进度、平板支撑有效时长、休息即将结束、达到目标、下一组或动作切换、结束保存结果，以及根据动作速度变化产生的休息提醒。

默认适中模式每组最多2次中途进度，积极模式最多3次，安静模式关闭中途进度但保留阶段及问题提示。播报有冷却、过期检查与用户优先规则；不会每次重复动作都报数。自由训练达到目标只提醒，不自动结束。

本地状态决定何时播报、播报哪些数字和问题。主动鼓励的模型请求使用 `tools: []` 与 `tool_choice: none`，只补充简短陪伴措辞，不能调用这23个工具或自行调整计划、次数、负重。

完整链路为：麦克风采集 → 本地人声检测与语句切分 → ASR语音转文字 → 本地快捷路由或模型工具决策 → 本地执行与真实回执 → 流式文字/逐句语音合成 → 播放及字幕。

- 开启收音后直接说话，没有接入唤醒词。训练页开启摄像头后，在用户仍希望收音的条件下自动开启麦克风；离开训练页会停止收音。
- 语音检测会保留句首音频，当前以约0.64秒静音作为句尾条件，连续输入最长约15秒后分段。
- 用户开口可以打断生成、ASR、TTS和播放；旧请求的迟到结果会被丢弃。语音派发在等待摄像头及排队保存后检查取消信号，未执行的旧操作不再补执行；已经成功的操作不会因打断而自动撤销。
- ASR有常见噪声/无意义转写过滤，播放期间的转写还会与近期播报比较以过滤回声。这些机制不等于已验证远场双讲表现。
- 确切的短命令可跳过LLM，例如暂停、开始训练、常用换动作、改本组次数、新一组、常见画面指令；仍需要ASR识别输入，语音回复仍需要TTS。
- 复杂自然语言与复合请求走模型工具决策，最多8轮；工具按结果逐项执行，部分成功后失败不会整体回滚。
- 查询可以先播一句具体处理意图，操作成功会给真实回执，正式答案独立处理；不把模型说“已完成”当作执行证据。
- 一般训练建议有直接回答路径，不一定调用工具；当前状态问题使用随请求注入的状态快照，不需要独立状态工具。
- 会话上下文保留最近8条用户/助手消息，约4轮；长期用户资料通过 `remember` 单独保存。
- 摄像头视频与姿态分析在本机处理。当前LLM交互提供文字、结构化训练状态、历史概况、用户资料和知识检索结果，未接入摄像头图像/视频的直接模型理解。ASR、LLM、TTS使用所配置的后端服务，因此不属于完整离线语音系统。

## 当前能力边界与需要区分的入口

- 音色：设置界面提供8种已批准音色（4男4女），代码默认W01清透自然；可以试听、选择并保存，但没有模型可调用的“切换音色”工具。
- 麦克风、扬声器和摄像头设备选择目前走界面设置；没有对应模型工具。`camera` 只控制摄像头开关，不选择摄像头设备；总播报开关已有speech_control工具。
- 提醒密度和播报控制同时有本地完整短句入口和模型工具；任意自然语言仍依赖模型理解，本次通过的样本不代表所有说法都已穷尽。
- `set_tempo` 目前是参数设置能力，不应描述成已经实现语音逐拍带练。
- `start_program` 可以立即执行多动作计划，但没有“仅保存计划模板”“修改整份正在执行的计划”“预约未来训练”的独立工具；已有参数工具能做的当前组修改仍受状态限制。
- 语音可查询训练历史，但没有修改/删除历史记录、导入导出数据、恢复最近删除内容的工具；这些不能因界面可能具备而算作语音工具。
- 未接入联网搜索、日历操作、账号登录、第三方健康数据或外部健身器械控制协议。
- 计数、站位检查、动作纠错均以本地规则和可见关节为依据；计数成功、没有故障提示或模型的鼓励措辞都不等于完整姿势已经通过评估。
