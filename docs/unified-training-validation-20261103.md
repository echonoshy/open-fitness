## 交付行为

- 默认打开「训练」，沿用原计数训练的摄像头、关节点、背景虚化、取景、动作示范和语音入口。
- 自由跟练移到「动作库 → 我的跟练」，原有收藏和四个默认动作保留。轻量跟练继续按示范播放计时，不产生自动计数成绩。
- 动作库全部 582 个动作可进入统一训练界面：8 个自动计数、平板支撑姿态计时、573 个计时记录。动作卡片显示对应能力。
- 计时记录提供目标秒数、负重、自填次数、暂停、休息、继续、再来一组和结束保存。时长排除暂停和休息，不是姿态合格时长；摄像头关闭后仍可计时，切离训练页会暂停。
- 切换动作前保存当前组。计时动作的摄像头只处理取景和关节点展示，不向旧动作计数器输入帧，也不展示旧动作角度、故障和评分。
- 按完整名称语音选择动作；计时训练支持明确的开始、暂停、继续、结束、自填次数口令。其他问答没有训练操作工具，不代替执行结果。计时模式不运行自动训练计划和主动姿态纠错。
- 计时记录单独存放在 `timedRecords` / `timedCheckpoint`，出现在记录页对应分类；完整 JSON 备份包含两类记录和收藏。Strong / Hevy CSV 保留原有自动计数、姿态计时的交换范围，界面有明确说明。
