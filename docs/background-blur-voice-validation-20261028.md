# 背景虚化语音控制验证

版本：0.3.19；日期：2026-10-28。

## 交付与使用

- 桌面包：`/Users/lake/Desktop/viaim Coach 0.3.19/viaim Coach.app`
- 构建包：`desktop/release/0.3.19-internal/mac-arm64/viaim Coach.app`
- 训练页开启麦克风后，可说“打开背景虚化”“关闭背景虚化”“恢复清晰背景”。“画面”面板同时显示语音示例。
- 语音和手动开关共用 `App.dispatch(background_blur)`，通过同一持久化队列保存设置，随后由现有 Camera 显示开关应用。
- 摄像头关闭时只保存偏好，开启收据会说明下次打开摄像头时生效。
- 当前支持开关，不提供虚化强度、背景替换或前景虚化。

## 实现边界

明确、完整指令走已有本地语音快捷路由；自然说法通过原有模型工具流程调用 `background_blur`。否定、条件、引用、将来和复合句不被本地子串匹配。查询开关状态读取应用实际设置及效果异常提示。持久化失败不发成功收据；排队期间取消的指令不继续写入。

姿态 Worker、人体蒙版合成、动作识别、计数和取景算法本次均未修改。摄像头初始化故障不属于本次改动。
